# ARH-T-0006 · Add signed release artifact verification

## Intent

Add detached signature verification for remote release artifacts. Checksums fetched from the same channel as an artifact only detect accidental corruption; they do not stop an active attacker who can replace both files.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Runtime archives and workflow packs publish detached signatures. | Release artifact test validates expected files. |
| A2 | Installer, shell runtime update, and Rust workflow update verify signatures against a bundled public key for remote sources. | Focused tests cover success/failure. |
| A3 | Local development sources remain possible through an explicit local-only mode or documented bypass. | Docs and tests cover local path behavior. |
| A4 | Replaced artifact plus attacker-controlled `.sha256` is rejected without a valid signature. | Negative test proves fail-closed behavior. |

## Non-goals

- Secret key management automation beyond documenting key rotation and expected signer input.
