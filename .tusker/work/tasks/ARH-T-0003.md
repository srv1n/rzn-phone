# ARH-T-0003 · Fix CLI boolean flag contract and rerun argv round-trip

## Intent

Fix the public CLI boolean contract. Docs use `--commit 0|1`, `--disconnect-on-finish 0|1`, and `--fast 0|1`, but the current clap bools reject values or cannot be turned off. `rzn-phone rerun` also reconstructs argv with separate boolean values that can become bogus workflow positionals.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Documented boolean run flags accept `--flag`, `--flag 0`, `--flag 1`, `--flag=true`, and `--flag=false` where appropriate. | CLI parser tests or smoke commands. |
| A2 | Cleanup flags can be explicitly disabled; `--dry-run` remains the safe no-commit alias. | Parser tests cover defaults and overrides. |
| A3 | `rzn-phone rerun <n>` emits valid argv, preferably `--flag=value`, and round-trips history entries. | History/rerun regression test. |
| A4 | README, App Store, LinkedIn, and Reddit copy-paste examples parse. | Scripted doc-example parse smoke. |

## Non-goals

- Changing workflow safety semantics beyond parsing the documented values.
