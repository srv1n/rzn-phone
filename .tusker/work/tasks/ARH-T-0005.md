# ARH-T-0005 · Strip heavy artifacts from workflow trace payloads

## Intent

Slim workflow traces so they do not embed complete tool results with screenshot base64, full UI XML, or page source. Trace should stay useful for debugging without multiplying response size and MCP token cost.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Trace entries keep step metadata, duration, ok/error state, error details, and compact result summaries. | Regression test inspects trace shape. |
| A2 | Raw `data`, full `source`, screenshots, and page XML are omitted from trace or replaced with digest/length/mime metadata. | Regression test covers screenshot/source steps. |
| A3 | Output templates and saved variables still receive required raw data. | Regression test covers `saveAs` plus output templating. |
| A4 | Trace payload size stays bounded for screenshot/source workflows. | Test asserts no raw artifact fields in trace. |

## Non-goals

- Removing artifacts from top-level structured output where callers intentionally requested them.
