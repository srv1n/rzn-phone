# ARH-T-0001 · Harden workflow update archive verification and extraction

## Intent

Bring the Rust `rzn-phone workflows update` path up to the same security bar as the shell runtime updater. It currently stages a workflow tarball in a predictable temp path, shells out to `tar -xzf`, and replaces installed resources without verifying a checksum or validating archive members.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | `rzn-phone workflows update` verifies the adjacent `.sha256` before replacing installed resources. | Focused tests cover valid checksum and checksum mismatch. |
| A2 | Archive extraction rejects absolute paths, parent traversal, symlinks/hardlinks, special files, special mode bits, and world-writable members. | Malicious archive tests fail before install mutation. |
| A3 | Remote update/install sources reject plaintext HTTP while local paths and `file://` still work. | Unit or integration tests cover remote/local source handling. |
| A4 | Temp extraction uses a unique private temp directory and cleans it up. | Code review plus focused tempdir test. |

## Non-goals

- Detached signature verification; that is ARH-T-0006.
- Reworking the release artifact layout.
