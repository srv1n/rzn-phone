# ARH-T-0007 · Align workflow step timeout with cold session creation

## Intent

Align workflow runner step timeouts with cold real-device session creation. The runner's generic 120s step timeout can cancel `ios.session.create` even though the tool's WebDriver/WDA timeout defaults to 600s.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | `ios.session.create` workflow steps default to at least `sessionCreateTimeoutMs` plus a cleanup buffer unless explicitly overridden. | Focused workflow runner test. |
| A2 | Timeout errors still record clear TIMEOUT details and run failed-session cleanup. | Focused timeout test. |
| A3 | Explicit shorter step timeouts remain honored when a workflow deliberately sets them. | Regression test. |

## Non-goals

- Changing Appium/WDA default timeout values unless tests show they are wrong.

## Verification

| Covers | Check | Result | Notes |
|---|---|---|---|
| A1,focused_test | cargo test -p rzn_phone_worker workflow_session_create | pass | 2 passed; default ios.session.create workflow timeout uses substituted sessionCreateTimeoutMs plus 15000ms cleanup buffer. |
| A3,focused_test | cargo test -p rzn_phone_worker workflow_session_create | pass | 2 passed; explicit shorter ios.session.create step timeout remains honored. |
| A2,focused_test | cargo test -p rzn_phone_worker session_create_timeout_records_timeout_details_and_cleanup_attempt | pass | 1 passed; mocked Appium create-session timeout returns typed TIMEOUT details and records failed-session cleanup attempt. |
| A1,A2,A3,broad_test | cargo test -p rzn_phone_worker --lib | pass | 99 passed; cheap broader crate library regression suite. |
