# ARH-T-0002 · Gate ios.web.wait_js like raw JavaScript execution

## Intent

Treat `ios.web.wait_js` as raw JavaScript execution. It polls caller-provided JS and can run side effects, so the current low-risk direct-call policy undermines the `ios.web.eval_js` direct-call ban.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | `policy_for_tool("ios.web.wait_js")` reports high risk and is not allowed for direct calls by default. | Unit test covers metadata and direct enforcement. |
| A2 | Workflow use remains allowed for trusted packaged workflows. | Unit test covers workflow allowance. |
| A3 | Tool description/metadata clearly says caller JS can have side effects. | Snapshot/unit test or direct schema assertion. |
